# 3️⃣ Integration Rules (Strict)

### API Wrapper

All network requests MUST go through:

```
js/api.js
```

Rules:

* Reads `window.API_BASE`
* Automatically attaches JWT from localStorage
* Handles:

  * 401 auto-logout
  * JSON parsing
  * Error normalization

---

### Socket Rules

All socket logic must exist only in:

```
js/socket.js
```

Handshake:

```js
io(API_BASE, {
  auth: { token }
});
```

# 4️⃣ API Contract (Exact — Must Not Be Modified)

### Authentication

```
POST /api/auth/login
Body: { email, password }
Returns: { success, token, user }
```

---

### Products

```
GET /api/products?page=&limit=
GET /api/products/:id
POST /api/products
PUT /api/products/:id
DELETE /api/products/:id
```

---

### Messages

```
GET /api/messages/:receiverId?page=&limit=
POST /api/messages/:receiverId
GET /api/messages/conversations/list?page=&limit=
PUT /api/messages/read/:conversationId
```

---

### Weather

```
GET /api/resources/weather?lat=&lon=
```

---

### Socket.io Events

Client emits:

* joinConversation
* leaveConversation
* typing
* stopTyping

Server emits:

* newMessage
* notification
* messagesRead
* typing

The admin manages the entire ecosystem, ensuring trust and smooth operations.
User & Vendor Verification: Approval workflows for farmer and buyer registrations to prevent fraud.
Global Catalog Management: Standardizing product listings (e.g., specific grades of cocoa or cassava) across different sellers.
Commission & Escrow Control: Managing split payments, where a percentage is held until delivery is confirmed.
Market Price Monitoring: Real-time updates of commodity prices from national markets to prevent exploitation.
Logistics & Transporter Tracking: Oversight of third-party transporters and delivery statuses to ensure perishable goods arrive fresh.
Dispute Resolution: Tools to mediate issues between buyers and sellers regarding product quality or payment.
2. Farmer/Seller Dashboard (The Storefront)
Farmers need tools to manage their "digital farm" and reach buyers beyond local markets.
Inventory & Yield Forecasting: Tracking current stock and predicting future harvest volumes.
Order Management: A clear view of pending, active, and completed sales with automated invoicing.
Digital Wallet & Payments: Integration of mobile money (MTN/Orange) for fast, secure payouts.
Agricultural Advisory: Access to weather alerts, soil health data, and pest warnings.
Direct Messaging: Secure chat to negotiate prices and delivery details with potential buyers.
3. Buyer Dashboard (The Procurement Tool)
Designed for wholesalers, restaurants, or individual consumers.
Product Sourcing & Filters: Search by category, region (e.g., "Onions from the North"), and organic certification.
Bid/Offer System: Ability to place bulk bids or request quotes for large agricultural orders.
Live Shipment Tracking: Real-time visibility of where their produce is during transport.
Rating & Review System: Building trust by rating farmers based on produce quality and reliability.
4. Market Gaps: How to Upgrade in Cameroon
Existing platforms like Camagro and eFarm.cm often struggle with certain areas you can improve:
Offline Capability: Most farmers in rural Cameroon have poor internet. Build an SMS/USSD gateway so they can update stock without data.
Trust through Escrow: Many local sites lack secure payment. Implementing a 45% upfront / 55% on delivery escrow system prevents scams.
Language Inclusivity: Include support for Pidgin, French, and local dialects (via voice or text) to reach less-literate farmers.
Last-Mile Logistics: Partner with local bike/truck unions and integrate their tracking into your admin panel to solve the "rural road" barrier.
